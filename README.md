# Book-keeping F2 SB ADT Conversion

Static ADT Studio web publication for **Book-keeping for Secondary Schools: Student's Book Form Two**.

## Status

- ADT book label: `book-keeping-f2-sb`
- Source PDF pages: 152
- Published pages: cover plus 151 generated page HTML files
- Revision: source-measured layout, 16 October 2026
- English read-aloud: 186 recorded clips with word highlighting
- Source PDF: not included
- ADT database/cache/logs: not included
- License: no separate reuse license is granted by this repository

## Open

Open `index.html` from a static web server. The bundle includes the generated HTML, images, fonts, CSS, JavaScript runtime, content catalogs, and IMS manifest needed by the ADT reader.

[Read the book online](https://aloycius.github.io/book-keeping-f2-sb-adt/).
Use the speaker control for read-aloud. On mobile, open the accessibility menu
and select **Text to speech**. Playback includes pause, stop, speed, and volume.

The revised edition preserves the source's word coordinates, embedded fonts,
rotated accounting tables, figure positions, and page artwork. Text is selectable
HTML, with real table cells. All 152 pages were checked against the PDF, and
playback was tested on desktop and mobile. Word timing is estimated, not
human-verified forced alignment; synthesized narration may still mispronounce
individual terms or figures.

## Provenance

Converted with ADT Studio from the user's local source PDF using the `adt-book-conversion` workflow. The source PDF remains the visual and content authority; this repository contains only the generated static web output.
