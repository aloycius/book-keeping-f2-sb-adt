Posting transactions from the petty cash book to ledgers

The double entry completion for items recorded in the petty cash book is done by posting
the totals of each column to the respective expense account. It also includes posting the
transfer of petty cash float in the main cash account. This is done periodically, usually at
each reimbursement time. The petty cash book in example 1.9 can be used to illustrate
how to complete double entry. At this stage, there is no need to balance these ledger
accounts, because there would probably be some more entries into these accounts in
the next round of imprest. The balancing of the specific expense accounts would be
done when the business wants to extract a trial balance. The following are the ledgers
