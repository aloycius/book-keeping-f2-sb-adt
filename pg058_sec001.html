and an undercast of a credit balance

These errors will not affect trial balance
because they will cancel each other. In this
case, the errors involve the same amounts
and thus cancel each other. Such errors
are discovered by tracing and vouching,
together with recasting the ledger accounts.

Considering the given examples, it can
be noted that compensating errors are
not a common thing in accounts. This
is because it is rare to have such errors
involving equal amounts and affecting
opposite sides. However, there is one
common situation where compensating
errors can be found. This happens when
there is an error in calculating the totals on
a special journal. To understand this, you
may need to refresh your understanding of
the postings from the special journals.

(a) Individual entries made in the special
journals (daybooks) are posted to the
sales ledger and purchases ledger

(individual accounts of debtors and
creditors) as follows:

(i)
For the sales journal, posting is

done to the sales ledger by posting

to the debit side of the individual debtors accounts.

(ii)
For the sales return journal,
posting is done to the sales ledger

by posting to the credit side of the

individual debtors accounts.

(iii) For the purchases journal, posting

is done to the purchases ledger by

posting to the credit side of the

individual creditors accounts.

(iv) For the purchases return journal,

posting is done to the purchases

ledger by posting to the debit side

of the individual creditors accounts.

(b) The totals in the journals are posted to
the general ledger as follows:

(i)
For the sales journal, posting

is done by debiting the trade

receivables account and crediting
the sales account.

(ii) For the sales return journal,

posting is done by debiting the

sales returns/returns inwards

account and crediting the trade

receivables account.

(iii)
For the purchases journal, posting
is done by debiting the purchases

account and crediting the trade

payables account.

(iv) For the purchases return journal,

posting is done by debiting the

trade payables account and

crediting the purchases returns/

returns outwards account.
